# 미림 랜선 검사실

브라우저에서 UTP 랜선 제작을 **단계마다 손으로** 연습하는 2D 교실 실습입니다. Papers, Please 식 금속 책상 위 작업이고, 버튼을 연타해 단계를 건너뛰는 흐름은 없습니다.

**GitHub Pages:** https://progh2.github.io/lan-cable-lab/

첫 의뢰는 고정입니다. **Cat5e 1m 스트레이트, 양끝 T568B, 관통형 RJ45, 부트 필수.**

## 로컬 실행

빌드 도구는 없습니다. 정적 HTML/CSS/JS입니다.

```bash
./serve.sh
```

또는 `python3 -m http.server 8080`

## 수업에서 하는 일

작업지시서는 항상 보입니다. 한 번에 한 작업만 열립니다.

1. 여러 릴 중 재킷 인쇄를 읽고 Cat5e를 고릅니다.
2. 릴에서 당겨 약 1.00m(±5cm)를 푼 뒤, 자유 끝이 아니라 릴 쪽을 자릅니다.
3. 관통형에 맞게 약 3cm 벗깁니다.
4. 페어를 풀고 가닥 8줄을 직접 폅니다.
5. T568B 순서로 칸에 끌어 넣습니다. 자동 정렬 없음.
6. 부트를 먼저 끼웁니다. 양쪽 모두.
7. 관통형 RJ45에 밀어 가닥이 앞에서 나오게 합니다.
8. 앞면 출구 색을 확인합니다. 틀리면 빼서 다시 정렬합니다.
9. 크림퍼를 올리고 쥐어 여분을 자릅니다.

끝 A가 끝나면 케이블 그림이 바뀝니다(왼쪽 플러그, 오른쪽은 아직 벗기지 않음). 끝 B는 탈피부터 압착까지 다시 합니다.

스마트폰에서는 큰 드래그 영역을 씁니다.
